# 🚀 Outskill Elevate — AI Sales Consultant

> **"Know the prospect. Understand their AI opportunity. Know what to say."**

An internal sales intelligence tool for Outskill sales agents during live prospect calls.

🔗 **Live Production URL:** [https://outskill-ai-sales-consultant.vercel.app](https://outskill-ai-sales-consultant.vercel.app)

---

## ✨ Features

- **Interactive Vanta.js Topology Background**: Real-time topological mesh animation powered by `p5.js` with mouse and touch responsiveness.
- **45+ Modern Professions**: Filter across 12 distinct categories (Marketing & Growth, Engineering, Sales, Data, Product, Operations, Legal, etc.) including high-demand roles like *AI Generalist*, *Influencer Marketing Lead*, *Prompt Engineer*, *Growth Hacker*, and *Cybersecurity Analyst*.
- **Multi-Select Roles**: Select multiple disciplines (e.g. Marketing + Sales) with 1-click unselect and clear options.
- **Seniority Tiers**: Tailored guidance across `1–3 years`, `3–5 years`, `5–10 years`, and `More than 10 years`.
- **Live Sales Intelligence**:
  - **Your Pitch**: Consultative talk-track pointers structured specifically for the prospect's role and seniority.
  - **AI Opportunities**: 3–4 practical AI applications and leverage points.
  - **Potential Areas to Explore**: 2–3 consultative discovery questions and pain points.
  - **Relevant Real Startups**: 3–4 verified domain companies building AI in their field with direct links and live research capability.
  - **Tailored AI Tools**: Smart-filtered bonus tools selected from Outskill's 1-year software licenses (Supergrow, Numerous AI, Lyzr AI, Fireflies, Wispr Flow, Phot.AI, etc.).
- **Browser History Integration**: Native Back/Forward button support with automatic state reset on return to welcome.

## 🛠️ Tech Stack

- **Framework**: [Next.js 14](https://nextjs.org/) (App Router, Server & Client Components)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/) (Custom BentoML & Awwwards High-Contrast Palette)
- **Visuals & Motion**: [Vanta.js](https://www.vantajs.com/) Topology + [p5.js](https://p5js.org/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Deployment**: [Vercel](https://vercel.com/)

## 🚀 Quick Start

1. **Clone the repository**:
   ```bash
   git clone https://github.com/Sibuna86/Elevate-Outskill.git
   cd Elevate-Outskill
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Run the development server**:
   ```bash
   npm run dev
   ```

4. **Open in browser**:
   Navigate to [http://localhost:3000](http://localhost:3000).
